# Руководство пользователя (demo)

Этот документ описывает demo-аккаунт и типовой пользовательский путь.

## Demo-учётные записи

| Роль | Email | Пароль |
|------|-------|--------|
| User | `demo@okak.app` | `Okak1Demo!!!` |
| Admin | `admin@okak.app` | задаётся `ADMIN_PASSWORD` (по умолчанию `admin_local`) |

Email обоих аккаунтов считается подтверждённым через seed.

## Сценарий «Первый запуск»

1. Открыть iOS-приложение (или вызвать `POST /auth/register`).
2. Ввести email, пароль и дату рождения (валидация 18+). На указанный email приходит код подтверждения (в dev — лог backend).
3. Ввести код в окне подтверждения. После успешной верификации происходит автоматический логин.
4. Главный экран показывает домашнюю вкладку с быстрым доступом к чатам и истории.

## AI чат

1. Кнопка «Новый чат» создаёт чат с моделью `okak-standard` и reasoning `medium`.
2. В шапке доступны параметры: модель, уровень reasoning, флаги `search` и `streaming`.
3. При отправке сообщения интерфейс мгновенно показывает сообщение пользователя, затем стримит ответ. Квота уменьшается, бейдж в шапке обновляется.
4. При исчерпании квоты появится ошибка `QUOTA_EXCEEDED` с предложением открыть магазин подписок.

## Магазин подписок

1. Вкладка «Магазин» загружает каталог из `/catalog/subscriptions`.
2. На карточке тарифа показывается описание, лимит запросов и список фич.
3. По нажатию «Купить» создаётся заказ + mock-платёж. iOS открывает mock-экран, где можно «оплатить», «отменить» или «отклонить».
4. На «успехе» подписка активируется, квота сразу же увеличивается, баланс возвращается на экран магазина.

## Управление подпиской

- «Активные подписки» — список действующих тарифов, кнопки `Отменить` и `Продлить`.
- Отмена выключает авто-продление и оставляет тариф активным до `end_date`.
- «История заказов» показывает статусы оплаты с цветовой маркировкой.

## Аккаунт

- Профиль: имя, язык интерфейса, тема, интересы (AI-персонализация). Кнопка «Сбросить персонализацию AI» очищает интересы и стиль.
- Настройки: язык, тема, уведомления, аналитика — изменения сохраняются автоматически.
- Сессии: список устройств с возможностью завершить любое (включая текущую сессию).
- Выход: уничтожает access/refresh токены локально и завершает текущую сессию.

## Восстановление пароля

1. На экране входа нажать «Забыли пароль?».
2. Ввести email — придёт код/ссылка.
3. Ввести новый пароль и код — пароль обновится, сессия очищается, пользователь возвращается на экран входа.

## Admin

- `http://127.0.0.1:3001/` (только loopback).
- Basic Auth `admin`/`admin_local` (изменяется через `.env`).
- Доступны KPI, поиск пользователей, история заказов и CRUD над тарифами.
